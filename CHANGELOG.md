# Changelog

## 0.1.0 (first public beta)

- Turntable-style sampler as VST3, Audio Unit and standalone app; universal binary (Apple Silicon + Intel), macOS 11+.
- Load WAV / AIFF / MP3 (and FLAC, M4A, CAF, OGG) by drag and drop; sample BPM from the file name or auto-detected.
- Varispeed platter, scratching (S + mouse, or drag the record), tape stop with adjustable time (0 = instant), play/pause with tape ramp, hard restart at cue.
- Loops with beat snap, loop in/out keys, 8 loop pads (tap an empty pad to save a loop), undo/redo.
- Beat repeater 1/1 to 1/16 bar with dry/wet mix; the track keeps running underneath.
- BPM sync to the host or a system BPM knob, smooth tempo changes, keep-pitch mode with semitone shift.
- XY low-pass filter (cutoff / resonance), output gain and meter, waveform overview.
- Keyboard shortcuts for every control, stored in an editable JSON file, layout-aware (US, German, Austrian, ...).
- Skins: Studio Ink, Liquid Glass, Retro '97.
- Everything is saved with your DAW project.
